SeoSonar 98 Help & Technical Reference Guide

Comprehensive Technical SEO & Performance Inspection

SeoSonar 98 is an ultra-fast, authentic Windows 98-styled website audit utility designed for technical SEOs, webmasters, and software engineers. Built with vanilla web standards and executing on modern edge functions, SeoSonar inspects critical search ranking factors without loading client-side dependencies.

What SeoSonar Inspects

  • Desktop & Mobile Core Web Vitals: Largest Contentful Paint (LCP), Cumulative Layout Shift (CLS), Total Blocking Time (TBT), and First Contentful Paint (FCP) evaluated via speed tests and lab data.
  • Global Probe Latency: Distributed real-time HTTP probes across 5 major continental regions (North America, Europe, South America, Asia-Pacific, Africa) via a distributed edge probe network.
  • On-Page Technical SEO: Quantitative audits of title length (30-60 chars), meta description length (120-160 chars), exactly one H1 heading structure, canonical link tag validity, mobile viewport configuration, missing image alt attributes, and HTML lang attributes.
  • Crawl & Indexation Directives: Availability of root robots.txt, XML sitemap discovery, HTTPS enforcement, and redirect chain count.
  • HTTP Security Headers: Strict-Transport-Security (HSTS), Content-Security-Policy (CSP), X-Content-Type-Options, X-Frame-Options, and compression encoding.
  • Structured Data: Detection and extraction of embedded JSON-LD schemas (Organization, WebSite, Article, Product, FAQPage).

How the Win98 System Rating is Calculated

The System Rating (0 to 100) provides a balanced benchmark configured via a single transparent formula:

Audit Dimension Formula Weight
Performance (Average of Desktop and Mobile) 35%
On-Page Technical SEO 35%
Accessibility Compliance 15%
Web Best Practices 15%

A penalty (up to 15 points) is deducted if remote probe servers in the United States, Germany, Brazil, Japan, or Morocco encounter latency higher than 1500 ms or return non-200 HTTP statuses.

Frequently Asked Questions

Why are Desktop results rendered alongside Mobile results?

Desktop (PC) browsing accounts for substantial B2B, enterprise, and e-commerce traffic. Inspecting both viewports reveals whether optimization efforts have inadvertently harmed desktop rendering while tuning for mobile viewports.

What does "Estimated (lab data unavailable)" indicate?

When a scan runs without speed test lab data, SeoSonar employs its native edge analysis engine based on server TTFB, DOM size, and asset analysis. This is transparently tagged so you always know whether data originates from speed tests or our native edge heuristic.

How does Server-Side Request Forgery (SSRF) protection work?

Before issuing requests, SeoSonar resolves hostnames via DNS-over-HTTPS and verifies that target addresses are not in private (RFC 1918), loopback, link-local, or cloud metadata ranges.
